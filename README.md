# hotel-venecia-fallas

Microweb de reservas del **Hotel Venecia Plaza Centro** para las **Fallas 2027**
(ver las mascletàs desde el hotel). Astro + Vercel + Airtable.

👉 Lee **[BRIEF.md](./BRIEF.md)** para el contexto completo, las decisiones y lo
que falta.

```bash
npm install
npm run dev
```
